# Pictochat

As the name suggests, this is a recreation of the software Pictochat from the Nintendo DS.
<br>
This project's intent is to get a dive into JS React by attempting to port the Pictochat design and behaviour onto the browser.
<br>
The current focus of the UI is for desktop resolutions. While this website may technically work for mobile layouts, it is probably very unpractical to use.

## Setup

To build this project, ensure NodeJS is installed and run:
<br>
<code>npm install</code>

The website can be launched by running:
<br>
<code>npm run dev</code>

Afterwards, it can be viewed on the url:
<br>
<code>http://localhost:8001/</code>
<br>

To build this as a static website for production, run:
<br>
<code>npm run build</code>
